# Sky Sailer

魔法のヨットで結晶を集めながら、雲海や氷の海を越えて船着場を目指すゲームです。

## 航海を始める

1. ホームの風景カードを横にスワイプするか、矢印・コース番号でコースを選びます。
2. 「航海の設定」で重力とジャンプの強さを調整します。
3. 「出航する」を押して冒険を始めます。

## コース

| コース | 世界と仕掛け |
| --- | --- |
| 1-1 雲海の航路 | 水路、渦、滝の落差と滝登り |
| 2-1 氷晶の海 | 氷山、落下するツララ、吹雪 |
| 3-1 砂漠のオアシス | サボテン、オアシスの滝、砂嵐 |
| 4-1 雲の階段 | 雲の切れ目、階段、大きな下り、上昇気流 |

航海が進むと、晴れから悪天候へ、そして再び晴れへと景色が変わります。

## 操作

| 操作 | キーボード | 画面のボタン |
| --- | --- | --- |
| 減速・加速 | ←・→ | 左・右 |
| ジャンプ | Space・↑・W | A・上向きボタン |
| ブースト | Shift | B |
| 押している間、完全停止 | ↓ | 下向きボタン |
| 停泊・航海再開 | S | STOP / SAIL |
| 一時停止・再開 | Escape | Pause |

スマートフォンでは縦持ちで遊べます。ゲーム画面の下にあるタッチパッドを使って操作してください。

## 航海のコツ

- 結晶を取ると追い風が吹き、速度が上がります。続けて集めると追い風が長く続きます。
- 水路や雲の切れ目はジャンプで越えましょう。ブーストを組み合わせると遠くまで進めます。
- 滝登りや上昇気流に入ると、上の足場へ運ばれます。
- 氷山、ツララ、サボテンなどの障害物を避けましょう。危険が迫ったら、停止して通り過ぎるのを待つこともできます。
- GUIDEをオンにすると、接触する部分に精霊のような温かい金色の光が現れます。

## クリアと再挑戦

船着場に到着するとクリアです。航海時間、ミス、集めた結晶に応じて、S・A・B・Cのランクが表示されます。

ミスが3回になるか、180秒が経過すると航海終了です。ダメージを受けても後ろには戻りません。落下したときは、現在位置または前方の足場へ復帰します。

終了画面から同じコースに再挑戦できます。クリア後は次のコースへ進むこともできます。

## 音楽と一時停止

- ステージBGMは最初からオンです。音が出ない場合はゲーム画面をクリックするか、操作キーを押してください。
- ホームのBGMボタンでは、1-1の音楽を楽しめます。
- BGMの音量と効果音は、それぞれ調整できます。4-1のBGMは未設定です。
- Pauseボタンや別のタブへの移動で、航海を一時停止できます。
